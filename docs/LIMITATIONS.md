# Ограничения

## Android

- Служба специальных возможностей не читает чужие системные диалоги с `FLAG_SECURE` (банки,
  некоторые платёжные экраны, скрытые поля). Скриншот таких экранов тоже недоступен.
- Экран блокировки и кнопка питания агенту недоступны.
- Жесты работают только пока служба включена и приложение не убито системой. На агрессивных
  OEM-прошивках (Xiaomi, Huawei, Samsung) нужно отключить энергосбережение для приложения.
- WebView часто отдаёт пустое или урезанное дерево. Здесь помогает Vision-скриншот, но если
  приложение ставит `FLAG_SECURE` — не поможет и он.
- Имена приложений ищутся по подписи лаунчера. Если подпись не совпала с командой, шаг завершится
  ошибкой «приложение не найдено».
- Vision-скриншот требует Android 11+ (API 30, `AccessibilityService.takeScreenshot`). На Android
  8–10 работает только Accessibility-дерево.
- На Samsung One UI и части OEM список Accessibility прячется глубже, а жесты иногда отменяются
  энергосбережением.

## Google Play

Использование Accessibility для общей автоматизации противоречит политике Play, если это не помощь
пользователям с ограниченными возможностями. Поэтому архитектура разделена:

- **Main App** рассчитан на sideload / F-Droid / свой сайт.
- **Companion Agent** — отдельный APK-инструмент, который ставится отдельно и держит MCP-сервер.

Публикация в Play возможна только после переработки под политику (например, как средство
доступности с явным обоснованием) — это вне рамок текущей сборки.

## Финансы

Банковские пакеты и кошельки в denylist. Даже если пакет не распознан, слова «Оплатить»,
«Купить», «Удалить», «Send money» требуют подтверждения. Повторять такое действие агент не будет.

## Голос

- Голосовой ввод использует системный `SpeechRecognizer` — качество зависит от установленного
  движка распознавания и наличия интернета у него.
- Озвучка ответов (TTS) пока не входит в сборку — в roadmap.

## MCP / Companion

- MCP-сервер слушает только `127.0.0.1` — внешние агенты должны работать на том же устройстве
  либо пробрасывать порт через `adb reverse` / туннель.
- `run_task` в Companion не содержит собственного LLM-планировщика: он возвращает подсказку
  использовать атомарные инструменты. Полноценный планировщик живёт в Main App.
- MCP-клиенты обычно говорят по stdio — нужен мост `mcp-remote` (см. README).

## Не входит в эту сборку (roadmap)

- On-device Vision (локальная мультимодальная модель без облака).
- TTS-озвучка статусов.
- Синхронизация сценариев между устройствами и шаринг.
- Двусторонний канал Companion ↔ Main App (удалённый запуск задач, синхронизация истории).
